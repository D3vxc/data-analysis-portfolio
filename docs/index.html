A result that went against me

My dissertation asked whether pairing an anomaly detector with a trained model catches attacks nobody has labelled. Across eight holdout runs it did not: the hybrid scored 0.9836 against the plain model's 0.9837. It helps in one narrow case, with almost no labels, and the write-up says so.
